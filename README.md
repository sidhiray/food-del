# Food Delivery App

## 📌 Description
A full-stack food ordering web application that allows users to browse food items, add them to the cart, and make secure online payments. Built using the MERN stack and integrated with Stripe API.

## 🛠 Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- Stripe API

## 🚀 Features
- User registration and login (authentication)
- Browse and filter food items
- Add to cart and remove items
- Secure Stripe payment gateway integration
- Admin panel for managing items
